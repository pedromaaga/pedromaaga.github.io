Project Library AI for Junior Company Management

A platform built to help a junior company organize and manage all project activity in one place. It syncs with Google Drive to keep every project file connected, while AI reads each document and highlights the most relevant information.

The system also includes a project management workspace with Slack integration, and an AI assistant that uses the combined project data to guide users through planning, execution, and follow-up.

Google Drive sync for project documents

AI extraction of key document insights

Slack-connected project collaboration

AI chat assistant for workflow guidance

Users can start new tasks already aware of what was done in similar projects, and the AI summarizes conversations, topics, and progress across the entire portfolio.
